A little about me

I enjoy the part of engineering where software architecture meets the reality of a business. Before choosing a framework or drawing a system boundary, I try to understand how the organisation works, where information gets lost, what must remain reliable, and which decisions the software is expected to support.

That way of thinking has naturally taken me toward backend architecture, enterprise integration, cloud delivery, and applied AI. I care about traceable flows, secure data handling, clear ownership between services, and systems that remain understandable after the first release.
