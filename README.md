A little about how I work

I enjoy the part of software engineering where technical choices meet business reality. I like understanding how an organisation works, where information gets lost, what must never fail, and which parts of a system should remain independent from one another.

That has led me toward backend architecture, enterprise integration, cloud delivery, and applied AI. I care about clear boundaries, traceable flows, secure data handling, and systems that a client can operate without depending on a developer for every change.
